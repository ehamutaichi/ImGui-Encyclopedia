# Dear ImGui v1.93.0 日本語解説図鑑

**コードと実際の表示を見比べながら、Dear ImGuiの使い方を調べられる非公式の日本語リファレンスです。**

初めてウィンドウやボタンを作るところから、ゲームエンジンのエディター、デバッグツール、拡張ライブラリの導入までを扱います。931宣言、81ガイド、470枚の実描画画像を収録しています。さらに、72型・556メンバーの役割や扱い方を調べられます。

## この図鑑で分かること

- **関数の使い方**：何ができるか、引数に何を渡すか、戻り値をどう使うかを確認できます。
- **型とメンバー**：ImFont・ImFontConfig・ImFontAtlas・ImGuiIO・ImGuiStyleなどのつながり、各メンバーの意味、所有権・寿命、設定用と内部状態の違いを調べられます。
- **コードと表示の対応**：実際のImGuiで描画した画像を、コード例と見比べられます。
- **フラグの選び方**：各値の意味、組み合わせ方、使うときの注意を調べられます。
- **入門から実践へ**：値の保持、IDと`##`・`###`、DX11/DX12の画像表示、Docking、独自描画などを学べます。
- **開発ツールへの応用**：インスペクター、ログ、時間計測、ノード編集、タイムラインなどの作り方を紹介しています。

## 使い方

初めて使う方は「入門・使い方」から、作りたい画面に近いガイドを選んでみてください。関数名が分かっている場合は「関数一覧」、設定値を調べたい場合は「フラグ一覧」、構造体や型の中身を調べたい場合は「型・構造体一覧」が入口になります。

関数名や日本語で検索でき、ひらがな・カタカナ・全角半角の違いを吸収します。よく使う用語の読みや言い換えで探せるほか、そのままの入力で見つからないときは軽い打ち間違いに近い候補も表示します。使用頻度の目安でも並べ替えられます。画像の拡大、コードのコピー、関連するAPIやガイドへの移動にも対応しています。ライト／ダークテーマと、コントラストの強さは表示設定から変更できます。

オフラインで読む場合は、リポジトリのファイルをダウンロード・展開し、`index.html`をブラウザーで開いてください。画像・スタイル・説明データは同梱の`site-assets/`から読み込みます。**index.htmlとsite-assetsは同じフォルダーに置き、JavaScriptを有効にしてください。** 閲覧用サーバーやC++のビルド環境は不要です。公式資料へのリンクを開くときはインターネット接続が必要です。

## 対象範囲とコード例について

Dear ImGui **v1.93.0**を基準に、標準版、Docking専用API、次の拡張ライブラリを区別して解説しています。

- **ImGuizmo**：3Dオブジェクトの移動・回転・拡縮ハンドル
- **imgui-node-editor**：ノード・ピン・接続線の編集画面
- **ImSequencer**：クリップを並べるタイムライン

拡張は掲載したコミットに固定しています。対象の版や実行条件は、サイト内の「資料情報」と各ガイドで確認できます。バックエンド全API、内部API全体、すべての入力条件や分岐を網羅する資料ではありません。

コード例には、有効なImGuiコンテキストやフレーム処理を用意して使う断片も含まれます。初期化、呼び出す順番、データの寿命については各解説を参照してください。画像は実行例であり、すべての環境で同じ表示・動作を保証するものではありません。
